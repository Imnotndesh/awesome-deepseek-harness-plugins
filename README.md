# Awesome DeepSeek Harness Plugins [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated collection of plugins, tools, and integrations for the [DeepSeek Harness](https://github.com/deepseek-ai) agent runtime.

A "harness" is the runtime loop that wraps an LLM — managing context, tools, memory, and control flow. This list collects community-built plugins that extend DeepSeek harness setups: tool integrations, memory backends, orchestration utilities, and more.

## Contributing

Contributions are welcome! Please open a pull request adding your plugin under the appropriate category, in this format:

```markdown
- [Plugin Name](https://github.com/user/repo) - One-line description of what it does.
```

Guidelines:

- One plugin per pull request.
- Keep descriptions short and factual.
- The plugin should work with DeepSeek models / harness setups.
